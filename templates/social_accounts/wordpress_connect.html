Connect WordPress

Publishes to your own WordPress site. Two things have to exist on the WordPress side first — the second one is easy to miss.

{% comment %} THE APPLICATION PASSWORD IS A SEPARATE STEP AND IT IS NOT OBVIOUS. Creating the user is the part people expect; that they must then generate a credential, on a different part of the profile screen, is the part they do not. Saying it in helper text under the field was not enough - it has to be stated before the form, as steps, or it reads as "type your password here" and fails. {% endcomment %}
  1. 1 Create a WordPress user with the Author or Editor role — not Administrator. Posts will appear as written by this user.
  2. 2 Generate an application password for that user. Log in as them, go to Users → Profile, scroll to Application Passwords, give it a name, and press Add. WordPress shows the password once — copy it then.
  3. 3 Paste all three below. The application password is not the user's own password.

An Administrator application password is a full site takeover if it ever leaks. {% endcomment %}
